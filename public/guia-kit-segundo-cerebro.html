KIT SEGUNDO CÉREBRO · PASSO A PASSO + CHECKLIST

Do arquivo baixado ao cérebro funcionando.

O kit é um cofre do Obsidian: as notas são arquivos de texto na sua máquina, você lê e navega por elas no Obsidian, e quem escreve nelas é o Claude Code. É essa dupla que dá memória permanente ao Claude, de uma conversa para a outra. Aqui está a instalação inteira, na ordem, com os comandos prontos para copiar.

Antes de começar

Duas coisas precisam estar certas antes do primeiro passo.

Se as duas já estiverem resolvidas, vá direto para o passo a passo. São elas que travam a instalação no meio do caminho.

Plano pago do Claude

O Claude Code exige uma assinatura paga do Claude: Pro, Max, Team ou Enterprise. O plano gratuito não inclui o Claude Code.

Quem usa a API pela Console também consegue, pelo caminho do terminal.

Computador compatível

Windows 10 ou mais novo, macOS 13 ou mais novo, ou Linux (Ubuntu ou Debian).

Não precisa de máquina potente: o cérebro são arquivos de texto.

Passo a passo

Cinco passos, do arquivo ao primeiro briefing

Siga na ordem. Cada passo termina com uma conferência, para você saber que deu certo antes de ir para o próximo.

01

Extrair o kit

Você já tem o arquivo: é o .zip que acabou de baixar no botão Baixar o kit, e ele costuma cair na pasta Downloads do seu computador. Se você entrou pela área de membros da Hubla, é o mesmo arquivo, no módulo Arquivos para instalar o cérebro.

Agora extraia o .zip:

  • Windows: clique com o botão direito no arquivo e escolha Extrair tudo. Abrir o .zip com dois cliques só mostra o conteúdo, não extrai, e o Claude não consegue trabalhar com os arquivos lá dentro.
  • Mac: dê dois cliques no arquivo.

Coloque a pasta extraída num lugar fácil de achar, como a pasta Documentos.

Confira: dentro da pasta do kit aparecem os arquivos CLAUDE.md e START-HERE.md. Se ao abrir a pasta aparecer só outra pasta dentro, a pasta certa é essa de dentro.
02

Instalar o Obsidian

O Obsidian é o app gratuito onde você lê e navega pelas notas do cérebro. Quem lê e escreve as notas é o Claude, então o cérebro funciona mesmo sem ele, mas é pelo Obsidian que você enxerga tudo.

  1. Acesse obsidian.md/download, baixe a versão do seu sistema e instale.
  2. Abra o Obsidian e clique em Abrir pasta como cofre (em inglês, Open folder as vault).
  3. Escolha a pasta do kit.
Confira: na barra lateral aparecem as pastas _knowledge, _memory, _pipeline, _decisions, _learnings, _prompts e _sessions.
03

Instalar o Claude Code

Escolha um dos dois caminhos. Se você nunca usou terminal, vá pelo Caminho A.

Caminho A: app do Claude, sem terminal

  1. Baixe o app do Claude em claude.com/download e instale.
  2. Abra o app e entre com a sua conta do Claude.
  3. Clique na aba Code, no topo da tela.

O app já vem com o Claude Code, então não precisa instalar Node.js nem rodar nada no terminal. Se a aba Code pedir upgrade, a sua conta ainda está no plano gratuito.

No Linux o app ainda está em beta. Lá o Caminho B é o mais direto.

Caminho B: terminal

Abra o terminal e rode o comando do seu sistema.

Mac ou Linux
curl -fsSL https://claude.ai/install.sh | bash
Windows, no PowerShell
irm https://claude.ai/install.ps1 | iex

O comando não mostra progresso enquanto baixa. Quando terminar, feche o terminal, abra de novo e confira:

Conferir a instalação
claude --version

Tem que aparecer um número de versão. Esse instalador não precisa de Node.js e se atualiza sozinho.

04

Abrir o Claude dentro da pasta do kit

Este é o passo que liga o Claude ao cérebro. Ele precisa ser aberto dentro da pasta do kit, não numa pasta acima nem numa pasta de dentro.

Caminho A, no app: na aba Code, escolha Local, clique em Select folder (Selecionar pasta) e escolha a pasta do kit.

Caminho B, no terminal: entre na pasta do kit e rode claude.

Mac ou Linux
cd ~/Documents/segundo-cerebro
claude
Windows, no PowerShell
cd $HOME\Documents\segundo-cerebro
claude

No terminal a pasta Documentos se chama Documents, mesmo com o computador em português. Troque segundo-cerebro pelo nome da sua pasta, se for diferente.

Na primeira vez, o claude abre o navegador para você entrar na sua conta. É só seguir os passos.

Nos dois caminhos: se o Claude perguntar se você confia nos arquivos da pasta, confirme. Com a pasta certa aberta, ele lê o CLAUDE.md sozinho e já segue as regras do cérebro.
05

Testar

Digite o comando abaixo e envie. Ao digitar só a barra, aparece a lista de comandos do kit.

O primeiro teste
/daily-briefing

Se tudo estiver certo, o cérebro gera um briefing do dia. Mesmo com os seus dados ainda em branco, ele já funciona.

Quando o Claude pedir permissão para criar ou editar um arquivo do cérebro, aprove. É assim que ele guarda a memória entre uma conversa e outra.
Próximo passo

Instalado é o modelo. Personalizado é o seu cérebro.

O guia de personalização vem dentro do próprio kit: é o arquivo guia-personalizacao.md, na raiz da pasta que você extraiu. Abra ele no Obsidian e siga por lá. São de 15 a 30 minutos para o essencial, e dá para ir completando com o tempo.

Ao lado, o resumo do que ele pede, para você já saber onde vai mexer.

O que a personalização cobre
  • Identidade no CLAUDE.md: nome, área de atuação, papel, objetivo principal e as ferramentas que você usa.
  • Base de conhecimento: os arquivos about-me, goals e projects dentro de _knowledge, nessa ordem.
  • Módulo de negócios, opcional: posicionamento, cliente ideal, serviços e preço, em _knowledge/business.
  • Consolidar o estado: rodar /end-session para gerar o primeiro estado real em _memory.

Os prompts da pasta _prompts fazem o Claude preencher isso junto com você.

Opcional

Backup e histórico com Git

Para ter backup e histórico das notas, dá para sincronizar a pasta com o GitHub. É opcional e mais indicado para quem já usa Git.

A

Pelo terminal

Criar o repositório local
cd ~/Documents/segundo-cerebro
git init
git add .
git commit -m "setup inicial do segundo cérebro"
git branch -M main

Crie um repositório privado no GitHub e conecte:

Conectar ao GitHub
git remote add origin https://github.com/seu-usuario/segundo-cerebro.git
git push -u origin main
B

Pelo Obsidian

  1. Vá em Configurações > Plugins da comunidade e ative os plugins da comunidade.
  2. Procure e instale o plugin Obsidian Git.
  3. Configure o plugin com o seu repositório do GitHub. Ele faz o backup sozinho de tempos em tempos.
O repositório tem que ser privado. O seu cérebro guarda informações pessoais.

Problemas comuns

O que costuma travar, e a saída de cada um

"claude não é reconhecido" ou "command not found"

Só acontece no Caminho B. Feche o terminal e abra de novo. Se continuar, a instalação não entrou no PATH do sistema: o passo a passo oficial está em code.claude.com/docs/en/troubleshoot-install.

Outra saída é usar o Caminho A, que não depende do terminal.

A aba Code pede upgrade

O Claude Code exige plano pago: Pro, Max, Team ou Enterprise. Confira o seu plano em claude.ai, em Configurações.

O Claude não sabe quem você é ou não segue as regras do cérebro

Você abriu a pasta errada, uma acima ou uma dentro da pasta do kit. A pasta certa é a que tem o CLAUDE.md direto dentro dela. Abra de novo escolhendo essa pasta.

Os comandos não aparecem quando eu digito a barra

Os comandos ficam na pasta .claude, que é oculta. Confira se ela veio junto na extração. No Windows, no Explorador de Arquivos: Exibir > Mostrar > Itens ocultos (no Windows 10, Exibir > Itens ocultos). No Mac, no Finder: Cmd + Shift + . (ponto).

Se a pasta .claude não estiver lá, extraia o .zip de novo e abra a pasta extraída.

O Obsidian não mostra as pastas

Você abriu outra pasta como cofre. Abra a pasta que tem o CLAUDE.md direto dentro dela.

Ficou travado em algum passo

O kit traz um atendente para isso: abra o arquivo prompt-suporte-llm.md, na raiz da pasta do kit, copie o conteúdo inteiro e cole como primeira mensagem num chat novo do Claude. Ele conhece o kit inteiro e ajuda no passo em que você parou.

Pronto

Cada sessão encerrada alimenta a memória, e o cérebro fica mais útil a cada semana de uso. O seu download e este guia continuam disponíveis na central de acessos, com o mesmo e-mail da compra.
