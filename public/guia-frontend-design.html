DIA 08/30 · 30 SKILLS DO CLAUDE · FRONTEND-DESIGN

Seu site tem cara de IA

É a skill oficial de design da Anthropic. Ela faz o Claude tratar cada tela como um projeto de estúdio: primeiro entende o assunto e o público, depois rascunha um pequeno sistema visual (paleta com 4 a 6 cores nomeadas, papel de cada fonte e desenho do layout) e confere esse rascunho contra o seu pedido antes de escrever o código. Ela também lista os vícios mais comuns de página gerada por IA, como fundo creme com detalhe cor de tijolo, cards idênticos com a mesma sombra e etiqueta em caixa alta acima de todo título, para o Claude evitar quando você não pediu.

O que ela faz

A skill oficial de design da Anthropic

Quem pede telas, páginas ou componentes ao Claude e quer que o resultado não tenha cara de modelo pronto.

Pra quem é

Quem pede telas, páginas ou componentes ao Claude e quer que o resultado não tenha cara de modelo pronto.

Dica

Fale o que o cliente vende e pra quem: a skill tira as escolhas de cor e fonte do mundo do assunto, então quanto mais concreto, mais único o resultado.

Dica

Peça para ela mostrar o plano antes do código; é ali que dá para cortar o que ficou genérico sem refazer a tela.

Dica

Ela recomenda gastar a ousadia em um ponto só da página e deixar o resto calmo; se algo ficou carregado, peça para tirar um enfeite.

Instalar

Copie e rode na ordem

Os comandos com barra (/plugin) você digita dentro do Claude Code. Os que começam com claude, npx, git ou pip vão no terminal. Se houver mais de um caminho, use só um.

01

No Claude Code (plugin oficial)

Digite dentro de uma sessão do Claude Code. O plugin frontend-design está publicado no marketplace claude-plugins-official da Anthropic.

Comando
/plugin install frontend-design@claude-plugins-official
02

No Claude Code (pelo repositório anthropics/skills)

Caminho que o README do repositório ensina. Instala o pacote example-skills, que traz a frontend-design junto com outras skills de exemplo (como theme-factory, canvas-design e skill-creator).

Comandos
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
03

No Claude.ai (site)

Segundo o README, as skills de exemplo deste repositório já estão disponíveis nos planos pagos do Claude.ai.

Como tirar o primeiro resultado

    

    

      
→
Do zero ao primeiro resultado
  • Instale a skill e abra o Claude Code na pasta do projeto.
  • No pedido, diga o que é o produto, pra quem é e qual o objetivo da página. A skill usa o assunto como fonte das escolhas visuais.
  • Se você não disser o assunto, ela propõe um (assunto, público e função da página) e pede sua confirmação antes de desenhar.
  • Leia o plano que ela mostra (cores, fontes, layout) e o que ela trocou por estar genérico, antes do código.
  • Se já tiver uma direção visual definida, escreva no pedido: a skill segue o que o pedido manda, mesmo que seja um dos visuais que ela evitaria.

    

  






  

    

      Pedidos prontos
      
Cole no Claude e troque os colchetes

      
Pedidos para testar a skill no primeiro dia. Ajuste ao seu caso.

    

    

      

        
01
Landing page de um cliente

        
Pedido 1
Use a skill frontend-design. Crie uma landing page para [nome do negócio], que vende [produto ou serviço] para [público]. O objetivo da página é [agendar uma conversa / vender / captar contato]. Antes do código, me mostre o plano de cores, fontes e layout e diga o que você mudou por estar genérico.

      

      

        
02
Refazer uma tela com cara de IA

        
Pedido 2
Use a skill frontend-design para redesenhar esta tela: [cole o código ou descreva]. Ela está com cara de modelo pronto. Mantenha o conteúdo e o funcionamento, e escolha paleta, tipografia e layout pensando em [assunto e público].

      

      

        
03
Só o plano visual

        
Pedido 3
Use a skill frontend-design, mas não escreva código ainda. Para um site de [assunto] voltado a [público], monte o plano: 4 a 6 cores com nome e código, as fontes e o papel de cada uma, e um esboço do layout. Depois revise o plano e aponte o que parece padrão.

      

      

        
04
Textos da interface

        
Pedido 4
Use a skill frontend-design para revisar os textos desta tela: [cole]. Quero botões que dizem exatamente o que acontece, mensagens de erro que explicam como resolver e nada de texto de enfeite.

      

    

  






  

    

      Cuidados
      
O que o próprio repositório avisa

    

    

      
Atenção
O README avisa que as skills do repositório são para demonstração e aprendizado: o comportamento no Claude pode diferir do mostrado, e é preciso testar no seu ambiente antes de depender delas em tarefa crítica.

      
Atenção
A skill trata alguns visuais como sinais de página feita por IA (por exemplo fundo creme com detalhe terracota, ou fundo quase preto com um único verde ácido), mas eles valem quando o pedido mandar.
